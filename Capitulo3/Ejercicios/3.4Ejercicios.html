Ejercicio 3.4: Verdadero o Falso

  1. Los navegadores que despliegan el tipo input color como campo de texto requieren que el usuario introduzca el nombre de un color.
    Respuesta: Falso. Requieren que se introduzca un código hexadecimal de color (por ejemplo, #ADD8E6), no el nombre del color.

  2. Cuando un usuario introduce datos en un formulario y luego lo envía (por lo general, al hacer clic en el botón Enviar), el navegador verifica de inmediato que los datos sean correctos.
    Respuesta: Verdadero. HTML5 ejecuta automáticamente las validaciones de cliente configuradas antes de despachar la petición al servidor.

  3. HTML5 puede validar si la dirección de correo electrónico introducida por el usuario existe en realidad.
    Respuesta: Falso. Solo valida la estructura sintáctica general (por ejemplo, que contenga usuario, @ y dominio), pero no puede comprobar si el buzón existe o está activo.

  4. Puede agregar required a cualquiera de los tipos input.
    Respuesta: Falso. required no está permitido ni aplica a ciertos tipos de input como hidden, range, color, button, submit o reset.

  5. Puede habilitar autocomplete sólo para ciertos elementos input.
    Respuesta: Verdadero. Se puede definir de forma individual agregando autocomplete="on" o autocomplete="off" directamente a elementos <input> concretos.

  6. El elemento time nos permite identificar una fecha, hora o ambas.
    Respuesta: Verdadero. Está diseñado para representar fechas, horas o combinaciones legibles por navegadores y motores de búsqueda.

  7. El elemento caption proporciona una leyenda para la imagen en un elemento figure.
    Respuesta: Falso. La etiqueta adecuada para <figure> es <figcaption>; <caption> se utiliza exclusivamente para títulos de tablas (<table>).

  8. El elemento details muestra una flecha que apunta a la derecha enseguida de un resumen o leyenda cuando el documento se despliega en un navegador. Al hacer clic en la flecha, ésta apunta hacia abajo y revela el contenido del elemento summary.
    Respuesta: Falso. La flecha acompaña al resumen definido en <summary>, y al pulsarla se despliega el resto del contenido del elemento <details> (la oración invierte quién se revela).

  9. El elemento footer describe el contenido que por lo general aparece en la parte inferior del contenido o del elemento section.
    Respuesta: Verdadero. Representa el pie de su sección o página contenedora, albergando habitualmente datos de autoría, enlaces legales o copyright.
