Ejercicio 8.13: Seguimiento de instrucción switch

Pregunta: ¿Qué valores se asignan a x cuando k tiene valores de 1, 2, 3, 4 y 10?

  • Cuando k = 1:

    Coincide con case 1:, donde solo se ejecuta break; sin modificar k. Luego se asigna x = k.
    → x = 1

  • Cuando k = 2:

    Coincide con case 2:. Al no tener instrucción ni break, pasa directo a case 3: (*fall-through*), ejecutando ++k (pasa a 3) y saliendo con break. Finalmente se asigna x = k.
    → x = 3

  • Cuando k = 3:

    Coincide con case 3:, se ejecuta ++k (pasa a 4) y sale con break. Luego se asigna x = k.
    → x = 4

  • Cuando k = 4:

    Coincide con case 4:, se ejecuta --k (pasa a 3) y sale con break. Luego se asigna x = k.
    → x = 3

  • Cuando k = 10:

    No coincide con ningún caso, por lo que entra al bloque default: ejecutando k *= 3 (10 * 3 = 30). Luego se asigna x = k.
    → x = 30
