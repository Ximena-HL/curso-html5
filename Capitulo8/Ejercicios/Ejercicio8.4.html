Ejercicio 8.4: Identificación y corrección de errores

a)

Errores: La palabra clave For inicia erróneamente con mayúscula (JavaScript distingue entre mayúsculas y minúsculas). Además, para contar en forma descendente desde 100 hasta 1 se debe decrementar la variable con --x en vez de ++x, de lo contrario se generaría un ciclo infinito.

Corrección:

for ( var x = 100; x >= 1; --x )
   document.writeln( x );

b)

Error: Falta la instrucción break; al final del case 0:. Sin break, la ejecución continuará hacia el case 1: (*fall-through*), imprimiendo "Entero par" y de inmediato "Entero impar" para los números pares.

Corrección:

switch ( valor % 2 )
{
   case 0:
      document.writeln( "Entero par" );
      break;
   case 1:
      document.writeln( "Entero impar" );
      break;
}

c)

Error: Para decrementar de dos en dos se debe usar el operador de asignación de resta -= en lugar de +=. Con x += 2, el valor de x aumenta constantemente (21, 23, ...) provocando un ciclo infinito.

Corrección:

for ( var x = 19; x >= 1; x -= 2 )
   document.writeln( x );

d)

Errores: La palabra clave While inicia erróneamente con mayúscula. Además, la condición contador < 100 no incluye el 100 en la impresión; para incluirlo debe ser contador <= 100.

Corrección:

var contador = 2;
do {
   document.writeln( contador );
   contador += 2;
} while ( contador <= 100 );
