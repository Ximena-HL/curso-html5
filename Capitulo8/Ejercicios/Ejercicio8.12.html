Ejercicio 8.12: Evaluación de expresiones lógicas

Valores dados: i = 1, j = 2, k = 3, m = 2.

Instrucción Salida en pantalla ¿Son necesarios los paréntesis?
document.writeln( i == 1 ); true No. Los operadores de igualdad tienen menor precedencia que los paréntesis de la llamada a la función, pero la expresión se evalúa de forma natural.
document.writeln( j == 3 ); false No.
document.writeln( i >= 1 && j < 4 ); true (ambas condiciones son verdaderas) No. Los operadores relacionales (>=, <) tienen mayor precedencia que el operador lógico AND (&&).
document.writeln( m <= 99 && k < m ); false (3 < 2 es falso) No. Los relacionales se evalúan antes que el &&.
document.writeln( j >= i || k == m ); true (2 >= 1 es verdadero) No. Los relacionales y de igualdad tienen mayor precedencia que el operador lógico OR (||).
document.writeln( k + m < j || 3 - j >= k ); false (5 < 2 es falso y 1 >= 3 es falso) No. Los operadores aritméticos (+, -) tienen la precedencia más alta, seguidos de los relacionales (<, >=) y finalmente el operador OR (||).
document.writeln( !( k > m ) ); false (!( 3 > 2 ) → !true) Sí. Son necesarios para que k > m se evalúe antes de aplicar el operador de negación lógica !, el cual posee una precedencia mayor que el operador relacional.
