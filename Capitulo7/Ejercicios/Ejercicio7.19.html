Ejercicio 7.19: El problema del else suelto

En JavaScript, un else se asocia por defecto con el if más cercano disponible a menos que se utilicen llaves { }.

Inciso b) Con llaves:

Las llaves encierran al if ( y > 10 ), forzando a que el else corresponda al if ( x < 10 ) exterior.

  • Para x = 9, y = 11: Cumple x < 10 y y > 10. Ejecuta el bloque interno y no entra al else. Imprime únicamente:
