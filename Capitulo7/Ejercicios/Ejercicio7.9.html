Ejercicio 7.9: Identificación y corrección de errores

a)

Error: Hay un punto y coma (;) al final de la condición del if, lo que finaliza prematuramente la estructura y deja al else huérfano, generando un error de sintaxis.

Corrección:

if ( edad >= 65 )
   document.writeln( "Edad es mayor o igual que 65" );
else
   document.writeln( "Edad es menor que 65" );

b)

Error: La variable total no fue inicializada numéricamente (contiene undefined). La operación total += x produce NaN.

Corrección:

var x = 1;
var total = 0;
while ( x <= 10 )
{
   total += x;
   ++x;
}

c)

Error: El ciclo while no tiene llaves { }. Solo la línea total += x; forma parte del cuerpo del ciclo, por lo que ++x; nunca se ejecuta y se genera un ciclo infinito.

Corrección:

var x = 1;
var total = 0;
while ( x <= 100 )
{
   total += x;
   ++x;
}

d)

Error: La variable y inicia en 5 y la condición es y > 0, pero se usa un incremento (++y). El valor de y aumenta continuamente hacia infinito, produciendo un ciclo infinito.

Corrección:

var y = 5;
while ( y > 0 )
{
   document.writeln( y );
   --y;
}
