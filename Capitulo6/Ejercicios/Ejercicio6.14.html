Ejercicio 6.14: Orden de evaluación de operadores

a) x = 7 + 3 * 6 / 2 - 1;

  • Paso 1: 3 * 6 = 18 (multiplicación)
  • Paso 2: 18 / 2 = 9 (división)
  • Paso 3: 7 + 9 = 16 (suma)
  • Paso 4: 16 - 1 = 15 (resta)
  • Paso 5: Asignación a x
  • Valor final de x: 15

b) x = 2 % 2 + 2 * 2 - 2 / 2;

  • Paso 1: 2 % 2 = 0 (módulo)
  • Paso 2: 2 * 2 = 4 (multiplicación)
  • Paso 3: 2 / 2 = 1 (división)
  • Paso 4: 0 + 4 = 4 (suma)
  • Paso 5: 4 - 1 = 3 (resta)
  • Paso 6: Asignación a x
  • Valor final de x: 3

c) x = ( 3 * 9 * ( 3 + ( 9 * 3 / ( 3 ) ) ) );

  • Paso 1: ( 3 ) = 3 (paréntesis interior)
  • Paso 2: 9 * 3 = 27 (multiplicación interior)
  • Paso 3: 27 / 3 = 9 (división interior)
  • Paso 4: 3 + 9 = 12 (suma dentro del paréntesis)
  • Paso 5: 3 * 9 = 27 (multiplicación de izquierda a derecha)
  • Paso 6: 27 * 12 = 324 (multiplicación final)
  • Paso 7: Asignación a x
  • Valor final de x: 324
