Ejercicio 6.13: Ecuación y = ax³ + 7

¿Cuáles de las siguientes instrucciones de JavaScript son correctas para la ecuación y = ax³ + 7?

  1. y = a * x * x * x + 7; → Correcta. Evalúa a * x * x * x y luego suma 7.
  2. y = a * x * x * (x + 7); → Incorrecta. Multiplica por (x + 7) alterando la fórmula.
  3. y = (a * x) * x * (x + 7); → Incorrecta. Agrupa erróneamente la suma con x.
  4. y = (a * x) * x * x + 7; → Correcta. Respeta el orden y la estructura algebraica.
  5. y = a * (x * x * x) + 7; → Correcta. Los paréntesis calculan x³ primero y luego multiplican por a.
  6. y = a * x * (x * x + 7); → Incorrecta. Realiza una distributiva que no equivale a la ecuación original.
