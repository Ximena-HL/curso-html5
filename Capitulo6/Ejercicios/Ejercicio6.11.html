Ejercicio 6.11: Diálogos de alerta (x = 2, y = 3)

  1. window.alert( "x = " + x ); → Muestra: x = 2
  2. window.alert( "El valor de x + x es " + ( x + x ) ); → Muestra: El valor de x + x es 4
  3. window.alert( "x =" ); → Muestra: x =
  4. window.alert( ( x + y ) + " = " + ( y + x ) ); → Muestra: 5 = 5
