Ejercicio 6.12: Modificación de variables

¿Cuál de las siguientes instrucciones de JavaScript contiene variables cuyos valores se modifican?

  1. p = i + j + k + 7; → Se modifica la variable p (mediante el operador de asignación =).
  2. window.alert( "variables cuyos valores se destruyen" ); → No modifica ninguna variable.
  3. window.alert( "a = 5" ); → No modifica ninguna variable (es solo una cadena de texto).
  4. cadenaVal = window.prompt( "Escriba una cadena:" ); → Se modifica la variable cadenaVal (recibe el valor retornado por el prompt).

Respuesta: Las instrucciones a) y d).
