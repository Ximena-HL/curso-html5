Ejercicio 9.30: Función Recursiva Misteriosa

Código analizado:

function misterio( a, b )
{
   if ( b == 1 )
      return a;
   else
      return a + misterio( a, b - 1 );
}

¿Qué hace esta función?

La función calcula el producto de dos enteros positivos (a × b) mediante sumas sucesivas.

Explicación: En cada llamada recursiva suma a y reduce b en 1, repitiéndose hasta que b llega al caso base (b == 1). Al final habrá sumado a exactamente b veces, lo que corresponde a la definición matemática de la multiplicación:

misterio(3, 4) = 3 + misterio(3, 3) = 3 + 3 + misterio(3, 2) = 3 + 3 + 3 + misterio(3, 1) = 3 + 3 + 3 + 3 = 12
